# Vision Studio — Android Starter 0.1

هذا مستودع تأسيسي لتطبيق Vision Studio على Android.

## ما يحتويه الآن
- واجهة Kotlin + Jetpack Compose.
- تصميم داكن ولمسات ذهبية.
- أقسام Media / Edit / Text / Audio / FX / Color.
- شاشة معاينة تجريبية وخطوط زمنية شكلية أولية.
- إعداد GitHub Actions لبناء APK تلقائيًا عند رفع التغييرات إلى main أو تشغيل workflow يدويًا.

## مهم
هذه النسخة **ليست محرر فيديو مكتملًا بعد**. عناصر المعاينة والطبقات والأزرار في هذه المرحلة هي هيكل واجهة، وليست قصًا أو تصديرًا أو مؤثرات عاملة. سنضيف الوظائف ونختبرها تدريجيًا.

## إنشاء APK من الهاتف
1. أنشئ مستودع GitHub جديدًا باسم `VisionStudio` واجعله Public لتسهيل البدء.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على المجلد المخفي `.github`.
3. افتح تبويب Actions في المستودع ووافق على تفعيل workflows إذا طُلب منك.
4. شغّل `Build Vision Studio APK` من Actions عبر `Run workflow`، أو انتظر انتهاء البناء بعد رفع الملفات.
5. افتح عملية البناء الناجحة، ثم نزّل Artifact باسم `Vision-Studio-debug-apk`.
6. فك ضغط الملف الناتج لتحصل على `app-debug.apk` وثبّته على هاتفك.

## المتطلبات التقنية
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- JDK 17
- Kotlin 1.9.25
- Compose Compiler 1.5.15
- Android SDK 35
